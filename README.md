# Uzum Kartochka Studiyasi

Model nomi va mahsulot suratini bering: AI rasmiy ma'lumotni topadi, matnni yozadi va Uzum uchun 3:4 kartochkalarni chizadi. Har rasm tagida e'tiroz yozib, AI'ga tuzattirish mumkin.

- `index.html`, `studio.js`, `studio.css`: yangi studiya
- `eski.html` (+ `app1.js`–`app7.js`, `style.css`): eski qo'lda tahrirlash studiyasi
- `api/ai.js`: OpenAI proksi (Vercel serverless funksiyasi)
- `logos/`: asl brend logotiplari

Vercel muhit o'zgaruvchilari: `OPENAI_API_KEY`, `STUDIO_PASS`.
